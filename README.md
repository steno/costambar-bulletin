# Costambar Community Bulletin — September 2026

Interactive web presentation of the APC Monthly Community Bulletin for Costambar, Puerto Plata.

**Live:** [https://steno.github.io/costambar-bulletin/](https://steno.github.io/costambar-bulletin/)

## View locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Controls

- Scroll / swipe between slides
- ↑ ↓ or arrow keys
- Top bar and right-side dots for jump navigation

Content and photos sourced from the September 2026 PDF bulletin.
